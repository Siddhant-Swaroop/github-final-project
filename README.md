# Simple Interest Calculator

A responsive, client-side web application built with HTML, CSS, and JavaScript designed to calculate simple interest and total maturity returns accurately and efficiently.

---

## 📌 Project Overview

This project provides a clean, user-friendly tool to calculate financial returns based on the Simple Interest method. It eliminates manual errors and helps users instantly visualize how money grows over time based on varying principal amounts, interest rates, and investment tenures.

---

## 🧮 How It Works

The calculation follows the standard mathematical Simple Interest formula:

$$\text{SI} = \frac{P \times R \times T}{100}$$

* **$P$ (Principal Amount):** The starting deposit or loan amount.
* **$R$ (Rate of Interest):** The annual rate in percentage ($R\%$).
* **$T$ (Time Period):** The tenure in years.
* **Total Maturity Value:** $\text{Total Amount} = P + \text{SI}$

---

## ✨ Features

* **Interactive Controls:** Adjust values easily using form inputs or dynamic sliders.
* **Instant Calculation:** Computes Simple Interest and total maturity amounts on the fly.
* **Input Validation:** Restricts invalid, negative, or blank values with clear error handling.
* **Responsive Layout:** Works smoothly on desktop, tablet, and mobile screens.
* **Lightweight & Fast:** Built entirely with vanilla web technologies without bulky third-party dependencies.

* **CSS3:** Modern styling, Flexbox/Grid layout, and responsive breakpoints.
